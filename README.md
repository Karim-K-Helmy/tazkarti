#  Tazkarti (تذكرتي)

##  About The Project
Tazkarti is a modern, fast, and user-friendly event booking platform. Built with a focus on world-class UI/UX, it allows users to effortlessly discover upcoming events, book tickets securely, and manage their profiles. The platform also includes a comprehensive dashboard for tracking statistics and managing operations.

##  Features
- ** Event Discovery:** Browse various categories including Concerts, Conferences, Sports, and Theater.
- ** Seamless Booking:** Interactive and intuitive ticket booking process.
- ** Authentication:** Secure user registration, login, and profile management.
- ** Interactive Dashboard:** A dedicated space for managing bookings, tracking statistics, and overseeing operations.
- ** Fully Responsive:** Pixel-perfect design that works flawlessly on mobile, tablet, and desktop devices.
- ** High Performance:** Optimized routing and rendering for maximum speed and SEO efficiency.

##  Tech Stack
- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Code Quality:** ESLint, Prettier
